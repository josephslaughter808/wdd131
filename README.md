# WDD 131: Dynamic Web Fundamentals

This repository contains front-end coursework completed while learning responsive web design and browser JavaScript.

## Skills practiced

- Semantic HTML
- Responsive CSS and media queries
- JavaScript arrays, objects, functions, and DOM updates
- Dynamic filtering and page rendering
- Forms and client-side interaction
- Image optimization and responsive assets
- Website planning and visual consistency

## Included work

- Responsive landing and place pages
- Temple galleries and dynamic filtering
- Product review and form workflows
- JavaScript and CSS exercises
- A final website plan with layout, typography, color, and content decisions

## Run locally

The projects use static HTML, CSS, and JavaScript. Clone the repository and serve it with a local web server:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

This repository is presented as coursework and documents my early front-end development progression.
